┌────────────────────────────────────────────────────────────────────────────┐
│                            功能说明                                         │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│  ✓ --check (-c)                                                            │
│    自动检查目录完整性，修复缺失的海报、NFO、缩略图等                         │
│                                                                            │
│  ✓ --poster (-p)                                                           │
│    下载刮削海报或从视频提取帧作为占位符                                      │
│                                                                            │
│  ✓ --nfo (-n)                                                              │
│    生成 Kodi 兼容的 NFO 元数据文件                                          │
│                                                                            │
│  ✓ --all (-a)                                                              │
│    执行全部操作（刮削+海报+NFO+重命名）                                    │
│                                                                            │
│  ✓ --force (-f)                                                            │
│    强制处理未匹配的文件                                                     │
│                                                                            │
│  ✓ --extract-frame (-e)                                                    │
│    即使有刮削数据也强制从视频提取帧                                         │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
